# 对象存储

本项目使用 Cloudflare R2，兼容 S3 API。所有访问密钥必须通过环境变量注入。

## 环境变量

```text
R2_ACCOUNT_ID=<cloudflare-account-id>
R2_ENDPOINT_URL=https://<cloudflare-account-id>.r2.cloudflarestorage.com
R2_ACCESS_KEY_ID=<r2-access-key-id>
R2_SECRET_ACCESS_KEY=<r2-secret-access-key>
R2_BUCKET=muran
R2_PREFIX=shortplay/
```

## 访问策略

- Bucket 默认不公开。
- 后端上传对象到 `R2_PREFIX` 下。
- 数据库存储稳定路径 `/uploads/<object-key>`。
- 前端读取 `/uploads/...`，由后端代理从 R2 拉取内容。
