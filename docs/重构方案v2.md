# 幕燃 (Muran) MVP v3 重构方案

## 目标

将当前三层分离架构（Router → Storage → db_store）重构为 Feature Module 架构，按用户功能组织代码，建立显式跨模块依赖规则。

## 核心原则

- **按功能组织**：每个 feature 对应一个用户可执行的操作（管理项目、生成分镜、生成视频...），不按数据实体拆分
- **厚 Service**：Service 是唯一的业务入口，Router 只做 HTTP 协议转换
- **显式依赖规则**：跨模块调用走 service 边界，不跨 feature 调 queries
- **保持函数式风格**：不加 class/接口抽象，纯函数 + 模块组织

## 单 Feature 内部结构

```
feature/
├── router.py      # HTTP 端点，仅做协议转换
├── service.py     # 业务流程、事务边界
├── queries.py     # SQLAlchemy 查询/写入函数（纯数据访问）
└── schemas.py     # 仅当该 feature 独有 Pydantic schema 变多时才加（可选）
```

## 跨模块依赖规则

```
router  →  service                       # Router 只能调 Service
service →  本 feature 的 queries          # Service 可以调自己的 queries
service →  其他 feature 的 service         # 跨模块走 service 边界
queries ✗  跨 feature 调用                # 不要跨 feature 调 queries
queries ✗  HTTPException                  # queries 不抛 HTTP 异常
HTTPException  →  仅在 router 层          # 协议转换在入口
```

### 依赖方向示例

```
storyboard/service.py:
  → shot/service.py          # 调 shot 的 service 保存分镜
  → ai/llm.py                # 调 LLM 生成
  → points/service.py        # 调积分扣费

video/service.py:
  → shot/service.py          # 查分镜数据
  → ai/video.py              # 调视频生成
  → points/service.py        # 调积分扣费

workspace/service.py:
  → project/queries.py       # ✗ 违规！应调 project/service.py
  → project/service.py       # ✓ 正确
```

## 错误处理模式

```python
# errors.py — 通用异常定义
class DomainError(Exception):
    def __init__(self, status_code: int, detail: str):
        self.status_code = status_code
        self.detail = detail

def not_found(msg="资源不存在"):
    return DomainError(404, msg)

def insufficient_points(needed, current):
    return DomainError(402, f"需要 {needed} 积分，当前 {current}")

# shared/router_utils.py — Router 层装饰器
def api_endpoint(fn):
    """DomainError → HTTPException 统一转换"""
    @wraps(fn)
    async def wrapper(*args, **kwargs):
        try:
            return await fn(*args, **kwargs)
        except DomainError as e:
            raise HTTPException(e.status_code, e.detail)
    return wrapper

# feature/router.py — 使用
@router.post("/episodes/{id}/storyboard")
@api_endpoint
async def generate_storyboard(id, user=Depends(get_user)):
    return await storyboard_service.generate(user, id)

# feature/service.py — 只管 raise DomainError
async def generate(user, episode_id):
    episode = episode_service.get_episode(episode_id)
    if not episode:
        raise not_found("剧集不存在")
    ...
```

## 重构优先级
